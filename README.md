proj-docker-nuvem-production.up.railway.app

Este trabalho tem como objetivo aplicar, na prática, o processo de conteinerização e publicação de uma aplicação, passando pelas seguintes etapas:

Conteinerizar o projeto utilizando Docker;
Testar a aplicação em ambiente local e validar seu funcionamento;
Versionar e disponibilizar o projeto no GitHub;
Realizar o deploy na nuvem utilizando Railway, tornando a aplicação acessível pela internet.
